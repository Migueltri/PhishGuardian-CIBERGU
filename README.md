# 🎨 Presentación 3D: Inteligencia Artificial y su Impacto en la Humanidad

## 📋 Resumen del Proyecto

He creado una **presentación interactiva con modelos 3D** sobre la Inteligencia Artificial y su impacto en la humanidad. Esta aplicación web moderna utiliza React, Three.js y Tailwind CSS para ofrecer una experiencia visual impactante y educativa.

## ✨ Características Principales

- ✅ **6 Diapositivas Interactivas** con contenido completo sobre IA
- ✅ **Modelos 3D Animados** únicos para cada diapositiva
- ✅ **Navegación Múltiple**: Botones, teclado e indicadores
- ✅ **Diseño Moderno** con gradientes y efectos visuales
- ✅ **Totalmente Funcional** y probado en navegador
- ✅ **Compilado para Producción** sin errores

## 🎯 Contenido de las Diapositivas

1. **Portada** - Cerebro 3D con red neuronal
2. **¿Qué es la IA?** - Red neuronal de 3 capas con conceptos clave
3. **Automatización** - Robot animado 3D
4. **Modelos de IA** - Cubos de datos (GPT-4, DALL-E, AlphaFold)
5. **Impacto Global** - Globo terráqueo con beneficios y desafíos
6. **El Futuro** - Toro y esfera representando colaboración humano-IA

## 🚀 Cómo Usar

### Iniciar la Aplicación

```bash
cd ai-presentation
npm start
```

La aplicación se abrirá en `http://localhost:3000`

### Controles

- **Siguiente**: Botón, Flecha →, o Espacio
- **Anterior**: Botón o Flecha ←
- **Ir a diapositiva**: Click en los indicadores de puntos
- **Rotar vista 3D**: Arrastrar con el mouse
- **Zoom**: Scroll del mouse

### Compilar para Producción

```bash
cd ai-presentation
npm run build
```
