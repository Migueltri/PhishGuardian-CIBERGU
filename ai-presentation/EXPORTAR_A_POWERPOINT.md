# Cómo Exportar a PowerPoint

Aunque esta presentación está diseñada como una aplicación web interactiva con modelos 3D, aquí te proporciono varias opciones para crear una versión de PowerPoint:

## Opción 1: Capturas de Pantalla (Más Rápido)

1. **Ejecuta la aplicación**:
   ```bash
   npm start
   ```

2. **Captura cada diapositiva**:
   - Navega por cada una de las 6 diapositivas
   - Presiona `F11` para pantalla completa
   - Toma capturas de pantalla (Windows: `Win + Shift + S`, Mac: `Cmd + Shift + 4`)
   - Guarda cada captura con el nombre de la diapositiva

3. **Crea el PowerPoint**:
   - Abre PowerPoint
   - Crea 6 diapositivas nuevas
   - Inserta cada captura de pantalla como fondo
   - Agrega el texto correspondiente sobre las imágenes

## Opción 2: Grabación de Video (Más Dinámico)

1. **Graba la presentación**:
   - Usa OBS Studio o similar para grabar la pantalla
   - Navega por todas las diapositivas mostrando las animaciones 3D
   - Guarda el video

2. **Inserta en PowerPoint**:
   - Crea una diapositiva de portada
   - Inserta el video en la segunda diapositiva
   - Configura para reproducción automática

## Opción 3: Exportar como PDF y Convertir

1. **Captura las diapositivas**:
   - Usa la herramienta de impresión del navegador (`Ctrl + P`)
   - Selecciona "Guardar como PDF"
   - Captura cada diapositiva individualmente

2. **Convierte a PowerPoint**:
   - Usa herramientas online como:
     - Adobe Acrobat (PDF a PPT)
     - Smallpdf.com
     - ilovepdf.com

## Opción 4: Presentación Web Embebida

1. **Despliega la aplicación**:
   - Sube la carpeta `build/` a un servicio de hosting:
     - Netlify (gratis)
     - Vercel (gratis)
     - GitHub Pages (gratis)

2. **Crea PowerPoint con enlaces**:
   - Crea diapositivas con títulos
   - Agrega un botón/enlace que diga "Ver Presentación Interactiva"
   - Enlaza a la URL donde desplegaste la aplicación

## Recursos de Imágenes Gratuitas

Para crear el PowerPoint manualmente, puedes usar imágenes de:
- **Unsplash.com** - Fotos de alta calidad
- **Pexels.com** - Imágenes y videos gratuitos
- **Pixabay.com** - Ilustraciones y fotos
- **Flaticon.com** - Iconos vectoriales
- **Freepik.com** - Vectores e ilustraciones

## Plantillas de PowerPoint Recomendadas

Busca plantillas con:
- Diseño moderno y tecnológico
- Colores azul, púrpura y gradientes
- Estilo minimalista
- Soporte para contenido visual

## Ventajas de la Versión Web vs PowerPoint

### Versión Web (Esta aplicación):
✅ Modelos 3D interactivos y animados
✅ Navegación fluida y moderna
✅ Rotación y zoom de objetos 3D
✅ Animaciones en tiempo real
✅ Experiencia inmersiva
✅ Accesible desde cualquier dispositivo con navegador

### PowerPoint Tradicional:
✅ Más familiar para audiencias corporativas
✅ Funciona sin conexión a internet
✅ Fácil de compartir como archivo
✅ Compatible con proyectores tradicionales
✅ Permite agregar notas del presentador

## Recomendación Final

Para la mejor experiencia, considera usar **ambas versiones**:

1. **PowerPoint** para:
   - Introducción y contexto
   - Notas y detalles técnicos
   - Distribución a la audiencia

2. **Aplicación Web** para:
   - Demostración visual impactante
   - Secciones interactivas
   - Wow factor y engagement

Puedes iniciar con PowerPoint y luego cambiar a la aplicación web para las secciones más visuales, o viceversa.
