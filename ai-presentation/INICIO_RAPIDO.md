# 🚀 Inicio Rápido

## Para Ver la Presentación AHORA

```bash
cd ai-presentation
npm start
```

Espera 10-15 segundos y la aplicación se abrirá automáticamente en tu navegador en `http://localhost:3000`

## Controles Básicos

- **Avanzar**: Click en "Siguiente" o presiona la tecla →
- **Retroceder**: Click en "Anterior" o presiona la tecla ←
- **Rotar vista 3D**: Arrastra con el mouse
- **Zoom**: Usa la rueda del mouse
